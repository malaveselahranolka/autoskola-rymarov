## Platform

web

## Stack

delegated: static HTML/CSS/vanilla JS, no build step. Chosen because the site is a single page, the incumbent is already static, and any static host works without a pipeline.

## Users

- Budoucí řidiči z Rýmařova a okolí (většinou 17–19 let) a jejich rodiče, kteří autoškolu vybírají a často platí. Na webu hledají: co autoškola nabízí, kdo učí, kde to je, kdy je teorie a jak se přihlásit. Převážně z mobilu.
- Profesionální řidiči (a jejich zaměstnavatelé), kteří potřebují školení profesní způsobilosti.
- Řidiči s oprávněním, kteří chtějí kondiční jízdy.

## Product Principles

1. Telefon je hlavní akce, vždy na dosah (zvlášť na mobilu).
2. Pravda místo marketingu: jeden instruktor, konkrétní auta, konkrétní adresa, konkrétní čtvrtky.
3. Mobil první: většina návštěv je z telefonu.
